🧠 Memory Match — Emoji Brain Game 🎮

Welcome to Memory Match, a fun and interactive emoji matching game designed to test and improve your memory! 🧩✨

🌟 About the Project

Memory Match is a beginner-friendly web development project where players find matching pairs of emojis within 60 seconds. The game includes a countdown timer, move counter, matched-pair tracker, and a restart option.

🎯 Features

- 🎮 Simple and interactive gameplay
- 🧠 8 matching pairs (16 cards in total)
- ⏱️ 60-second countdown timer
- 🔢 Move counter to track attempts
- 🎉 Matched-pair counter
- 🔄 Restart option to play again
- 📱 Responsive design for mobile devices
- 💻 Designed to work on laptop and desktop screens
- 🌙 Dark navy blue theme with teal accents

🛠️ Technologies Used

- 🧱 HTML5 — to structure the website
- 🎨 CSS3 — to style the game and make it responsive
- ⚙️ JavaScript — to handle card matching, moves, the timer, and game controls

🕹️ How to Play

1. Click Start Game to begin.
2. Click a card to reveal its emoji.
3. Click another card to find its matching pair.
4. Find all 8 pairs before the timer reaches zero.
5. Try to win using fewer moves!
6. Click Restart Game to play again.

📂 Project Files

- "index.html" — website structure and content
- "style.css" — styling, colors, and responsive layout
- "script.js" — game logic, card matching, timer, and buttons
